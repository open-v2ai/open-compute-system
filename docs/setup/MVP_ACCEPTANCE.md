# MVP 验收说明

当前产品是自托管 AI 推理商业化基础设施。模型 API 与 GPU 实例出租是两条主路径；拼租、裸金属询价和线索池已撤出，不再作为验收项。

## 可在本地验收的闭环

1. 访问首页和算力市场，按 GPU、区域、库存和价格筛选；
2. 使用演示账号登录，选择有库存 SKU 创建实例；
3. 接口以 `202` 返回实例 ID 与任务 ID，页面轮询到 `running`；
4. 复制 SSH 命令、查看 JupyterLab 地址（Mock 地址不可当真机可达）；
5. 关机、开机、再次关机并输入实例名释放；
6. 后台查看对应订单、实例、生命周期任务、库存和审计记录；
7. 后台调整 SKU 价格、上下架，并确认用户端不泄露供应成本。

账号当前可在本地验收：手机号或邮箱二选一注册/登录；登录后增加另一种绑定；同一账号使用两种方式登录；拒绝绑定其他账号已占用的手机号或邮箱；拒绝解绑最后一种登录方式。整个过程保持同一用户 ID，已有订单、实例、余额和用量归属不变。

模型 API 当前可在本地验收：

1. 查看模型目录与输入/输出 Token 价格；
2. 用户创建只显示一次的 API Key；
3. 使用 OpenAI 兼容 Chat Completions 发起流式或非流式请求；
4. 检查 Key 鉴权、吊销、余额不足与请求幂等；
5. 查看 Token 用量、余额扣减、模型副本和运营成本字段隔离；
6. 确认所有回复明确来自 Mock，不能当作真实模型输出。

## 自动化证据

- API 测试覆盖手机号/邮箱二选一注册登录、身份唯一性、绑定解绑、最后身份保护、公开成本脱敏、余额扣款/退款流水、请求摘要幂等、跨用户幂等隔离、完整实例生命周期、Outbox 卡死恢复、CSRF、后台 RBAC、审计；线索接口已删除并有 404 断言；
- 节点 Agent 测试覆盖认证、受控 Docker argv、幂等创建、配置冲突和删除；控制面测试覆盖节点健康、GPU/端口冲突边界、Agent 部署、推理副本生成、同步和停止；
- Alembic 包含初始 schema、Outbox 和交易/任务可靠性迁移，并支持验证后基线旧 `create_all` 数据库；`leads` 表为兼容保留，不再提供业务 API；
- Web 通过 ESLint、TypeScript、Vitest 和生产构建，并直接消费 OpenAPI 生成类型；
- `/health/live`、`/health/ready`、`/health/providers` 分离进程、依赖和 Provider 健康状态。

## 上线前仍需真实验收

- 合作方库存同步、创建、状态查询、开关机、释放与幂等能力；
- 真实 vLLM/NIM/OpenAI-compatible 端点、模型身份与 Token 用量核对；
- API Key 的生产 RPM/TPM/并发限流和多进程一致性；
- 模型商业使用许可、推理端点安全隔离和数据保留策略；
- 真实 GPU 节点上的 Docker socket、NVIDIA Container Toolkit、模型下载、vLLM 容器启动和部署生命周期；
- SSH/JupyterLab 实际访问以及平台与合作方最终状态核对；
- 手机短信与邮件验证码所有权验证、支付回调、计量、退款、实名和正式协议；
- PostgreSQL 备份恢复演练、HTTPS、后台独立域名、MFA 服务和网络访问策略。

仓库已经提供 HTTPS/独立后台域名/TOTP/网络频控配置，但正式证书、域名解析、真实 TOTP Secret 和部署环境仍需外部验收。
