## 1. 文档说明

### 1.1 本 PRD 解决什么问题

本项目不是只复刻一个官网首页，而是建设一套可真实运营的 GPU 算力供应平台，覆盖：

1. 对外官网与算力商品展示；
2. 手机号、微信、子账号等账户体系；
3. 容器云实例的购买、交付、连接和全生命周期管理；
4. 拼租卡、裸金属和企业定制询价；
5. 镜像、数据盘、共享文件存储与数据迁移；
6. 充值、余额、计费、订单、账单、优惠、退款与发票；
7. 实名认证、子账号、权限与团队预算；
8. 资源、库存、价格、订单、客户线索、内容和运维后台；
9. 帮助文档、在线客服和售后支持。

### 1.2 “100% 复现”的边界

本 PRD 将“100% 复现”定义为：

- 用户能完成与对标站一致的核心任务；
- 关键字段、状态、业务规则和异常分支完整；
- 运营人员能管理资源、价格、库存、订单和用户；
- 真实接入算力编排、支付、短信、实名认证等基础服务；
- 页面结构和交互密度可对标，但不复制对方商标、公司名、二维码、联系方式、原创图片、专有文案和源代码。

### 1.3 调研可信度标记

| 标记 | 含义 |
|---|---|
| A 已验证 | 在公开网站中实际打开或操作确认 |
| B 官方文档 | 来自对标站官方帮助文档，但未进入登录后真实控制台操作 |
| C 产品补全 | 为形成完整可运营闭环而补充的必需能力 |

### 1.4 当前未验证边界

以下能力因没有使用真实账号、余额和算力资源进行消费，不能宣称已经现场验证：

- 实际充值、支付回调和退款到账；
- 实际创建、启动、停止或释放 GPU 实例；
- 登录后控制台的全部视觉细节；
- 实际 JupyterLab、VSCode Web、SSH 地址和端口分配；
- 实名认证供应商流程；
- 发票真实审核和开具；
- 资源调度、计费结算和故障迁移的底层实现。

这些能力已依据官方文档整理为明确需求，上线前必须通过真实沙箱或生产前环境验收。

### 1.5 已确认的产品决策（2026-08-24）

| 决策项 | 已确认方案 |
|---|---|
| 算力来源 | 自有资源 + 少量固定算力供应合作方的混合模式 |
| 供应方接入 | 首期由平台内部人员配置和维护，不建设供应商登录后台 |
| 容器云交付 | 用户自助下单、支付/扣余额、系统自动调度和交付 |
| 裸金属交付 | 官网展示配置与参考价格，用户提交需求，销售人工报价和交付 |
| 拼租卡交付 | 首期作为产品展示和客户意向收集，由运营人工组团、联系和交付 |
| 首期主产品 | GPU 容器云；裸金属询价为辅助；拼租完整交易闭环后置 |
| 盈利方式 | 用户销售价与资源供应成本之间的价差；企业客户单独报价 |
| 管理后台 | 只建设平台内部运营后台，不建设外部供应商工作台 |

产品后续如开放供应商自主入驻，必须作为独立版本重新设计认证、上架审核、库存同步、分账结算、SLA 和争议处理，不在当前范围内。

## 2. 产品概述

### 2.1 产品定位

Open Compute System 面向企业与专业用户，提供从按需 GPU 容器、模型推理，到拼租整机、裸金属集群和企业 AI 基础设施的一站式算力服务。

### 2.2 核心价值

- 低门槛：按秒/小时、包日、包周、包月等灵活计费；
- 快交付：预装主流 AI 镜像，目标为分钟级内进入开发环境；
- 易开发：JupyterLab、VSCode Web、SSH、端口映射；
- 可复用：自定义镜像、克隆实例、同区复制数据盘；
- 可协作：子账号、资源权限、共享余额或独立配额；
- 可扩展：容器实例、拼租卡、裸金属、弹性集群、私有化方案；
- 可运营：库存、定价、订单、账单、优惠券、发票和客户线索统一管理。

### 2.3 目标用户

| 用户 | 典型诉求 | 首要功能 |
|---|---|---|
| 专业研究与工程用户 | 论文复现、模型微调、仿真、专业内容生产 | 按需 GPU、预装镜像、Jupyter、拼租卡 |
| AI 工程师与专业开发者 | AI 应用开发、ComfyUI、训练与推理服务 | 按量实例、开放端口、无卡启动 |
| AI 创业与专业团队 | 多成员协作、成本控制、持续推理 | 子账号、配额、镜像、共享存储 |
| 企业研发团队 | 大模型训练、稳定资源、合规交付 | 裸金属、集群建设、SLA、专属支持 |
| 采购/财务 | 充值、对公付款、账单、发票 | 费用中心、订单、发票、合同线索 |
| 平台运营 | 上架资源、调价、处理客户与订单 | 运营后台、库存、线索、优惠、内容 |
| 平台运维 | 节点、容器、告警、故障和审计 | 资源编排、监控、日志、风险控制 |

### 2.4 商业模式

1. 容器云：按量和包周期收入；
2. 数据盘、文件存储、自定义镜像：容量计费；
3. 拼租卡：按卡/月预付，成团后交付；
4. 裸金属：按台/月或定制合同；
5. 企业服务：硬件销售、集群建设、运维 SLA、AI 应用解决方案；
6. 增值服务：技术支持、迁移、私有化部署和定制镜像。

## 6. 账户与认证

### 6.1 登录（A/B）

支持四种方式：

1. 手机号 + 密码；
2. 手机号 + 6 位短信验证码；
3. 微信扫码；
4. 子账号用户名 + 密码。

密码登录字段：手机号、密码、记住账号、忘记密码。  
短信登录字段：手机号、6 位验证码、获取验证码。  
子账号格式：`账号名@账号域`。

规则：

- 未注册手机号使用短信登录时，可按产品策略自动注册；
- 验证码设置发送频率、错误次数、IP/设备限流；
- 登录失败不能暴露手机号是否注册；
- 支持登录态过期、异地登录提醒和主动退出；
- 成功后返回发起登录前页面。

### 6.2 注册（A）

字段：

- 手机号；
- 人机滑块验证；
- 6 位短信验证码；
- 密码；
- 确认密码；
- 邀请码（选填）；
- 同意服务协议、隐私政策、反挖矿协议。

规则：

- 密码 8-32 位，至少包含字母和数字；可要求混合符号；
- 注册协议不可默认静默同意，用户需要明确确认；
- 邀请码校验成功后绑定邀请关系，后续不可改绑；
- 注册、登录、验证码和风控事件写审计日志。

### 6.3 忘记密码与账户安全（A/B）

- 主账号：手机号验证码重置；
- 子账号：绑定手机号后可短信重置，也可由主账号重置；
- 已登录用户可通过原密码修改密码；
- 可绑定微信；解绑微信走安全校验或客服审核；
- 展示最近登录设备和安全事件（C，推荐）。

### 6.4 实名认证（B）

- 入口：控制台 → 个人资料 → 立即认证；
- 认证信息提交后不可自行修改；
- 认证状态：未认证、审核中、已认证、认证失败；
- 认证失败展示原因并允许重新提交；
- 已认证解锁发票、邀请奖励、开放公网端口和子账号创建等能力；
- 创建普通实例和充值不应强依赖实名认证；
- 敏感身份数据单独加密、最小权限访问并记录查看审计。

## 7. 容器云算力市场

### 7.1 商品筛选（A）

筛选维度：

- 计费方式：按量、包日、包周、包月、包夜；
- 地区/可用区；
- GPU 型号；
- GPU 数量：1、2、4、8；
- 是否有货；
- 排序字段：综合、价格等；
- 升序/降序；
- 卡片视图/列表视图。

交互规则：

- 多维筛选组合即时生效；
- 筛选条件同步 URL，支持复制和返回恢复；
- 无结果时给出清空筛选、订阅到货或联系客服；
- 库存和价格定时刷新，创建前必须再次校验；
- “只看有货”排除不可创建 SKU；
- 移动端筛选收纳到抽屉。

### 7.2 SKU 卡片（A）

字段：

- GPU 型号与显存；
- 地区/可用区；
- GPU 分配数量；
- CPU 厂商标签；
- vCPU；
- 内存；
- 系统盘；
- 默认数据盘及最大可扩容；
- 包日、包周、包月、按量价格；
- 优惠/热门标签；
- 库存状态；
- 立即创建或到货提醒。

库存状态至少包括：有货、紧张、无货、维护中、下架。

### 7.3 创建实例流程（B）

步骤：

1. 选择区域、GPU 型号与卡数；
2. 选择计费方式；
3. 选择镜像；
4. 配置系统盘和数据盘；
5. 填写实例名称等基础配置；
6. 展示价格明细、优惠抵扣和预计扣款；
7. 校验余额与库存；
8. 用户确认创建；
9. 创建订单并预占库存；
10. 调度容器，返回实例列表并展示进度。

### 8.2 实例状态机（C）

```text
创建中 -> 运行中 -> 关机中 -> 已关机 -> 开机中 -> 运行中
  |          |          |          |          |
创建失败   异常/欠费   关机失败   释放中    开机失败/排队
                                      |
                                    已释放
```

附加任务状态：镜像保存中、克隆中、迁移中、数据复制中、配置变更中、重置中。

规则：

- 冲突任务不能并发执行；
- 每个操作都返回任务状态和可追踪 ID；
- 页面刷新后仍能恢复真实状态；
- 前端禁止只靠乐观状态判断成功；
- 失败时展示可执行的恢复动作。

### 8.3 连接与开发（B）

支持：

- JupyterLab：Notebook、终端、文件管理、小文件上传；
- VSCode Web：浏览器内编辑和轻量开发；
- SSH：复制登录命令，支持密码或密钥；
- SCP/rsync：大文件上传下载；
- SSH 隧道：将远程服务映射到本地端口；
- 公网开放端口：生成专属外部访问地址；
- 自定义服务：展示端口、协议、访问地址和状态。

安全要求：

- SSH 密码不可在列表页长期明文展示；
- 支持重置凭据和密钥登录；
- 公网端口需实名认证、协议确认和风险提示；
- 对高风险端口、挖矿特征和异常流量触发风控；
- 自定义服务地址支持撤销；
- 所有连接凭据访问写审计日志。

### 8.4 实例生命周期操作（B）

| 操作 | 前置状态 | 核心规则 |
|---|---|---|
| 开机 | 已关机 | 按量实例需重新申请 GPU，可能排队或迁移 |
| 关机 | 运行中 | 按量实例停止 GPU 计费并释放 GPU；包时长仍保留资源 |
| 无卡启动 | 已关机 | 仅 CPU 模式，低价进行环境和数据准备 |
| 定时关机 | 运行中 | 指定时间或训练结束后自动关机 |
| 数据盘扩容 | 允许配置状态 | 最小 1GB，仅扩不缩，下次开机生效 |
| 升降配置 | 满足资源条件 | GPU 数变化，CPU/内存按比例联动 |
| 转换计费 | 合法计费状态 | 按量与包周期互转，按分段规则结算 |
| 重置系统 | 已关机 | 清空系统盘，保留数据盘 |
| 更换镜像 | 已关机 | 清空系统盘，保留数据盘 |
| 保存镜像 | 已关机 | 保存系统盘，不包含数据盘 |
| 克隆实例 | 可克隆状态 | 同区快速复制系统环境，可选复制数据盘 |
| 迁移实例 | 视方案而定 | 同区或跨区迁移环境与数据 |
| 复制数据盘 | 源关机、目标运行、同区 | 默认可复制全部或指定文件/目录 |
| 释放实例 | 已关机 | 永久删除系统盘与数据盘，不可恢复 |

关键规则：

- 按量实例关机后停止实例 GPU 计费；
- 连续关机达到平台配置天数后可自动释放，默认对标 7 天；
- 自动释放前至少进行多渠道提醒；
- 释放必须二次确认并输入实例名或验证码；
- 存在数据复制/镜像保存任务时禁止释放；
- 包周期续费、到期、宽限期和回收策略可配置。

## 10. 存储与数据管理

### 10.1 三类存储（B）

| 类型 | 默认路径 | 默认容量 | 生命周期 | 共享 |
|---|---|---:|---|---|
| 系统盘 | `/` | 30GB | 随实例释放 | 否 |
| 数据盘 | `/root/rivermind-data/` | 50GB 起 | 随实例释放 | 否 |
| 文件存储 | `/root/rivermind-fs/` | 按需 | 独立于实例 | 同一区域共享 |

规则：

- 数据盘适合训练数据和高频读写；
- 文件存储适合长期保存和跨实例共享，不推荐直接进行高性能训练；
- 文件存储按区域隔离；
- 每区域可配置免费额度，对标值为 20GB；
- 数据盘只允许扩容，不允许在线缩容；
- 释放实例前明确提示系统盘和数据盘会永久删除。

### 10.2 文件存储（B）

- 按区域开通；
- 文件浏览、新建文件夹、上传、下载、删除、重命名、移动；
- 展示容量、当日峰值、预计费用；
- 同区实例自动挂载；
- 子账号可被限制在指定子目录；
- 大文件提供 SCP/rsync 指引；
- 文件删除、覆盖和权限变更写审计日志。

### 10.3 数据复制与迁移（B）

同区复制数据盘：

- 源实例必须关机；
- 目标实例必须运行且同区；
- 可复制全部、指定文件或指定目录；
- 默认每日次数上限可配置，对标值 5 次；
- 同名文件可能覆盖，提交前必须提示；
- 复制期间限制相关实例开关机；
- 目标实例的 SSH/Jupyter 可继续使用；
- 展示进度、速度、已传输量、错误和重试。

跨区迁移推荐组合：自定义镜像 + SCP/rsync/网络云盘。

## 17. 运营后台

### 17.1 资源中心

管理层级：区域 → 可用区/机房 → 集群 → 节点 → GPU。  
字段至少包括：厂商、型号、显存、驱动、健康状态、总量、已分配、可售、保留、维护、温度、利用率。

能力：

- 节点注册、下线、维护、隔离；
- GPU 健康检查；
- 资源池和调度标签；
- 超售策略（默认禁止 GPU 超售）；
- 库存同步和异常校准；
- 容量趋势和缺货预警。

资源来源分为“自有”和“固定合作方”。合作方资源由内部运营人员录入或通过合作方 API 同步；合作方不直接登录本平台。

### 17.2 SKU 与定价

- 创建 SKU：区域、GPU 型号、卡数、vCPU、内存、磁盘、CPU 标签；
- 多计费价格：按量、日、周、月、夜间；
- 上下架、排序、推荐、热门、限时优惠；
- 库存阈值与“紧张”标签；
- 生效时间和价格版本；
- 企业专属价；
- 调价不影响已生效的包周期订单。

内部定价需同时维护“供应成本”和“用户销售价”，并计算单实例、单订单和时间周期毛利。供应成本只对具备财务权限的内部角色可见，严禁暴露到用户端接口。

### 17.3 实例与调度任务

- 全量实例搜索；
- 查看用户、节点、配置、镜像、费用和连接状态；
- 重试失败任务、迁移、隔离和强制关机；
- 高危操作必须二次确认和审计；
- 不允许后台直接无记录修改账单或余额。

### 17.4 交易与财务

- 充值单、支付回调、订单、账单、资金流水；
- 人工对公入账；
- 退款审批；
- 发票审核；
- 日结、对账、差异处理；
- 余额调整使用审批流和双人复核；
- 财务数据导出脱敏并记录审计。

### 17.5 拼租与裸金属

- 拼租产品、团、卡位、价格、成团阈值、截止时间；
- 手动成团、失败关闭、退款和交付；
- 线索去重、分配、跟进、标签、预计成交额；
- 免费测试审批、资源预留、到期回收；
- 报价单、合同编号和交付记录（P2）。

### 17.6 内容后台

- 首页推荐；
- 解决方案和关于我们；
- 公告、活动、弹窗；
- 帮助文档；
- 协议版本和强制重签；
- 客服二维码和联系方式。

### 17.7 风控与合规

- 手机号/IP/设备验证码频控；
- 支付和退款异常；
- 邀请作弊；
- 端口暴露风险；
- 挖矿进程、异常 GPU 满载、恶意扫描和带宽异常；
- 黑名单、风险等级、自动停机和人工复核；
- 协议版本、同意时间、IP 和用户代理留痕。

## 20. 非功能需求

### 20.1 性能

- 官网首屏 LCP：桌面端目标 ≤ 2.5 秒；
- 市场筛选响应目标 ≤ 500ms；
- 普通控制台 API P95 ≤ 500ms；
- 实例创建请求 2 秒内返回任务 ID；
- 真实资源交付时间单独监控，不用 HTTP 响应时间代替；
- 列表默认分页，库存和价格使用缓存但创建前强校验。

### 20.2 可用性

- 控制面目标可用性 ≥ 99.9%；
- 支付、计费和资金流水不得因消息重复或延迟造成重复入账；
- 调度、支付、通知使用可重试任务和死信队列；
- 核心配置、订单、资金和审计定期备份；
- 底层集群故障不应阻断用户查看账单和数据回收指引。

### 20.3 安全

- 密码使用强哈希；
- 身份信息、连接凭据、支付信息加密存储；
- 管理后台强制 MFA 和 RBAC；
- 防 CSRF、XSS、SQL 注入、SSRF、越权和重放；
- 下载、开放端口和实例代理防止路径穿越与内网探测；
- 关键动作二次确认；
- 资金操作双人复核；
- 秘钥不得进入日志；
- 定期漏洞扫描、依赖更新和灾备演练。

### 20.4 隐私与合规

- 明确收集手机号、实名、支付、发票、连接日志的目的；
- 最小化收集和展示；
- 公开隐私政策、服务协议、反挖矿协议；
- 支持账户注销和法定数据留存规则；
- 客服查看敏感信息需授权和审计；
- 公网服务、内容和计算任务遵守当地监管要求。

### 20.5 可观测性

监控：

- API 成功率、延迟、错误码；
- 注册、充值、创建实例漏斗；
- GPU 库存、分配率、利用率、温度、故障率；
- 调度时长、创建失败、开机失败、迁移失败；
- 用量采集延迟、账单差异、余额异常；
- 支付回调、退款、短信和通知送达；
- 拼团成团率、企业线索响应时长。

日志关联键：request_id、user_id、instance_id、order_id、task_id、payment_id。

## 27. 最终产品判断

对标网站的本质是三套业务叠加：

1. 面向专业用户的自助式 GPU 容器云与模型推理；
2. 面向长期专业负载的拼租与面向企业的裸金属交付；
3. 面向专业团队和企业的账户、数据、镜像、计费与技术服务体系。

如果只复刻首页和算力卡片，只完成了约三成产品。真正决定平台能否运营的是资源调度、实例状态机、可靠计费、资金流水、数据生命周期、权限和运营后台。项目应优先跑通真实 GPU 的“创建 → 使用 → 计费 → 关机 → 释放 → 对账”闭环，再扩展拼租、企业线索和完整视觉复现。
