# Support

Open Compute System is maintained by its community on a best-effort basis.

- Use **GitHub Discussions** for setup questions and design conversations.
- Use the bug report form for reproducible defects.
- Use the feature request form for scoped product proposals.
- Use private vulnerability reporting for security issues; see [`SECURITY.md`](SECURITY.md).

Please include the version or commit, operating system, Python/Node versions, deployment mode, and
sanitized logs. Never post API keys, cookies, database dumps, model credentials, or customer data.

The maintainers do not provide an SLA through public issues. Real GPU provider integration,
production deployment, commercial model licensing, payment, SMS, and regulatory compliance require
project-specific engineering and acceptance.
